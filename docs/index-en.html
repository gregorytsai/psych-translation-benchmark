A concrete image example

High text scores do not prevent a medication-label copy error.

In synthetic image case img-04, the source label is SERTRALINE while Gemma 4 26B's output shows SETRALINE (one R missing). All four applicable image reviewers flagged the medication-name mismatch; the image score was 72.

This is a synthetic evaluation image, not a real prescription. It is an exact benchmark observation, not a clinical conclusion.

Three takeaways from this test

Sample size matters when differences are small.

Read the full method →
01

26B and 31B are close

The shared text scores are 98.614 and 98.531, a difference of about 0.083 points. This run does not establish a clear winner.

02

31B leads on images, with only four images

Gemma 4 31B QAT scores 92.688 on the image set. It is a small descriptive sample, not a general visual claim.

03

26B has the shortest text response median

Its text response median is 0.686 seconds after loading in this fixed environment; it is not a hardware-independent promise.

Known context—and what this test adds

Established evidenceWhat this run adds
TranslateGemma is translation-specialized and built on Gemma 3. Its published broad-language benchmarks are not this Taiwan mental-health test.In this fixed English-to-Traditional-Chinese sample, Gemma 4 12B, 26B and 31B have higher text-panel means than TranslateGemma 27B. Different generations, quantization and templates prevent attributing the gap to specialization alone.
Gemma 4 26B A4B uses sparse expert activation; its efficiency-oriented design is already public.Here, 26B and 31B differ by only 0.083 text-panel points, while median warm request times are 0.686 s and 2.511 s. These are measurements of this setup, not a new discovery about MoE architecture.
LLM judges can exhibit position and preference biases. Agreement does not establish correctness.The top three remain the same when any one eligible judge is omitted, yet an actual Taiwan terminology criticism conflicts with official usage. Stable rankings and a wrong annotation can coexist.

These are observations from one frozen test, not claims of scientific priority or universal superiority.
