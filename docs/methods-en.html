Methods and limits

Test design, score calculation, and limits

This page documents the materials, inference settings, reviewer panels, score calculation, and response-time measures. Shared cases, reviewer-response latency, and translation warm-response time are different measurements.

01

Materials and sample

30 English text cases and 4 images; each of seven candidate models produced one translation per case, for 238 public model-case cells.

02

Inference settings

The translation run used fixed context, temperature 0, thinking off, and one request at a time. Full settings remain in the reproducible source.

03

AI reviewer design

Text used five reviewers; images used four fixed reviewers. This is an observed panel, not a human gold standard.

Shared-case inclusion

One invalid reviewer cell is excluded, not scored as zero.

A text shared-case item requires a complete five-reviewer panel. text-15 had one invalid reviewer cell, so model means use 29 shared items. The candidate translation and valid public information remain available.

The image shared set contains four images and four fixed reviewers per image. Mistral's image route was unsupported by design, so it was not filled with a low score.

How model scores are calculated

Average within each case, then across cases

Shared-case set

Complete shared cases: 29 text items and 4 image items; the original text sample still contains 30 cases.

Within-case and model mean

Valid reviewer scores are averaged within each case, then case means are averaged. The four rubric dimensions sum to 0–100.

Not a claim of

Translation accuracy, clinical safety, or a universal cross-model leaderboard.

Scoring rubric and reviewer agreement

Analysis limits

What this dataset can and cannot answer

Small sample30 text cases and 4 images; a top image score is not a general visual claim.
Panel is not goldReviewer agreement does not establish translation truth or clinical safety.
Images are not OCRImage results are end-to-end translation observations, not character-level OCR CER.
Speed is localGeneration medians depend on hardware, runtime, settings, and request content.
No full win ratePairwise comparisons are not a complete round-robin, so no full ranking is inferred.
Raw files stay privateThe site excludes raw attempts, absolute paths, PIDs, private bindings, and unprocessed logs.

Do model rankings change with the scoring criterion?

Across the 29 shared passages, TranslateGemma 27B had the highest mean for fluency. Gemma 4 31B QAT led on terminology and Taiwan usage. Gemma 4 26B had the highest means for meaning and safety, and for completeness and format.

The passages came from 12 source pages. We averaged the five judges within each passage, paired models by source and evaluated all 4,096 sign flips. The overall model-by-criterion interaction had p < 0.001. An exploratory analysis ranked the seven models on each passage, assigned ties their average rank and also gave p < 0.001.

There are 21 model pairs for each of the four criteria. After Holm correction across all 84 comparisons, none reached 0.05. The overall ranking pattern varies across criteria, but a change of place for a particular pair does not establish a significant difference. The test assumes the sign of each paired source-level difference is exchangeable under the null. We report descriptive scores and ranks for the four images.

Checking a terminology comment

In text-06, Gemma 4 31B QAT translated bipolar disorder as 雙相情緒障礙症. Mistral argued that 情緒 should be replaced with 情感. Taiwan’s National Health Insurance Administration and National Taiwan University Hospital’s Hsinchu Branch both use 雙相情緒障礙症. This check documents local usage for one example. The reported score is the one the judge originally gave.

Translation and judge settings

Translation used an 8,192-token context, a 4,096-token output limit, temperature 0, seed 20261023 and thinking disabled. The local judges used a 32,768-token context, a 16,384-token output limit and an 8,192-token reasoning budget.

In a separate test, the judges compared 168 supported pairs twice with the answer order reversed. Both orders produced the same winner for 112 pairs and a tie for seven. The other 49 pairs were set aside because the preference changed with the order. Mistral did not support another 12 image pairs. Only some model pairs were tested this way. The homepage uses the individual rubric ratings.
