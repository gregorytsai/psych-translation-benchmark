Methods and limits

Put each number back in context.

This page keeps the technical details short while explaining the distinctions most likely to be missed: shared cases, reviewer panels, and translation generation time are different things.

01

Fixed materials

30 English text cases and 4 images; every candidate model produced one translation per case, for 238 model-case cells.

02

Fixed settings

The frozen translation run used fixed context, temperature 0, thinking off, and one request at a time. Full settings remain in the reproducible source bundle.

03

Fixed panel

Text used five reviewers; images used four fixed reviewers. This is an observed panel, not a human gold standard.

Why 29?

One invalid cell is not a zero.

A text shared-case item requires a complete five-reviewer panel. text-15 had one invalid reviewer cell, so the shared text comparison contains 29 items. The candidate translation and valid information remain available.

The image shared set contains four images and four fixed reviewers per image. Mistral's image route was unsupported by design, so it was not filled with a low score.

How scores are formed

Shared-case reviewer means

Denominator

Complete shared-case items per track: 29 text items and 4 image items.

Score

Valid reviewer scores are averaged within each item, then averaged descriptively across shared items.

Not a claim of

Translation accuracy, clinical safety, or a universal cross-model leaderboard.

Traceable rubric and reliability

What each reviewer score means

The public instructions define four integer subscores for text and image jobs. They must sum exactly to the 0–100 score; this is not a fixed error-penalty table.

DimensionPointsReviewers inspect
Terminology & Taiwan usage0–30Medical/psychological terms and Taiwan Traditional Chinese, not Simplified Chinese.
Meaning & safety facts0–30Meaning, negation, medication, dose/number/unit, frequency, timing, conditions and suicide/self-harm meaning.
Fluency0–20Natural, clear Taiwan Traditional Chinese register.
Completeness & format0–20No omission/addition; preserve visible content, paragraph/list structure and relevant layout cues.

ICC is computed across 203 text translation units (29 cases × 7 models), each with five reviewer scores, and 28 image units (4 cases × 7 models), each with four scores—not across seven model means. ICC values describe agreement in reviewer scoring, not translation accuracy, an 87.4% correctness rate, or clinical safety. No confidence intervals are reported here; these are point estimates.

Limits

What this dataset cannot answer

Small sample30 text cases and 4 images; a top image score is not a general visual claim.
Panel is not goldReviewer agreement does not establish translation truth or clinical safety.
Images are not OCRImage results are end-to-end translation observations, not character-level OCR CER.
Speed is localGeneration medians depend on hardware, runtime, settings, and request content.
No full win ratePairwise comparisons are not a complete round-robin, so no full ranking is inferred.
Raw files stay privateThe site excludes raw attempts, absolute paths, PIDs, private bindings, and unprocessed logs.
Rebuild

Reproducible, with boundaries.

The site is rebuilt by build_site.py with the Python standard library. It reads the committed frozen CSV snapshot, applies an explicit allow-list, and writes docs. If the result or method files change, re-check public fields and licensing.

python build_site.py
python build_site.py --results <latest_results> --materials <materials>

An example where the judge needs checking

For Gemma 4 31B QAT, text-06, Mistral called 雙相情緒障礙症 non-standard and insisted on 情感. Taiwan’s NHI and a national university hospital use 雙相情緒障礙症. The categorical criticism is therefore not accepted as a demonstrated model error. The archived score is unchanged; this external check is an editorial annotation, not a new human-scored dataset.

Reproduction notes and audit corrections

Translation: context 8,192; output limit 4,096; thinking off; temperature 0; seed 20261023. Local judges: context 32,768; output limit 16,384; reasoning budget 8,192. The original general reproducibility note mixed these tracks; this site separates them using the configuration and runtime records.

Paired-order checks: 168 supported pairs (336 directions), comprising 112 consistent decisions, 7 consistent ties and 49 order-inconsistent abstentions. Another 12 Mistral image pairs were unsupported by design. This sparse comparison graph does not justify an all-model win-rate ranking.
