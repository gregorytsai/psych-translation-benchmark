How to read this model

Start with shared cases, then inspect outputs.

The text score uses 29 shared cases and five fixed reviewers; the image score uses four images and four fixed reviewers. These are observations, not a gold accuracy score, and incomplete panels are not filled with zeros.

The response medians come from the frozen translation run. They answer how long this configuration took after loading, not how fast every machine will be.

Traditional Chinese output excerpt

但有些有恐慌症的人會發展成恐慌障礙。他們會反覆發作恐慌症。這些發作可以一天發生好幾次，也可以一年只發生幾次。患有恐慌障礙的人通常會擔心再次發作。這可能會導致他們避免過去曾發作恐慌症的場所和情境。
